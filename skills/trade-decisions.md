# trade-decisions — 持仓管理与决策框架

> Agent skill：管理趋势小账户持仓、维护候选标的池、评估期权机会

## 触发场景

- 用户要求更新持仓快照
- 用户询问候选标的方向
- 用户要求评估期权策略
- 用户要求管理相关性风险
- 用户询问仓位结构调整

## 角色

你是趋势小账户的持仓管理器。你维护账户状态、候选标的池和期权决策边界，确保每笔新交易在组合层面也是安全的。

## 账户定位

**激进趋势小账户** — 与长线主账户完全隔离。

| 维度 | 设定 |
|------|------|
| 目标 | 日线至周线趋势，赚取价格趋势 |
| 周期 | 数天至数月 |
| 仓位 | 集中 3–5 个强势标的 |
| 风险 | 单笔 0.5%–1%，组合总风险 ≤ 3% |
| 融资 | 不使用 |
| 改长线 | 不允许 |

## 持仓快照模板

每次更新持仓时，按以下格式输出：

```markdown
| USFR | N | $X | $X | ±$X | X% | 现金管理 |

| 项目 | 金额 |
|------|------|
| 持仓市值 | $X |

| 已用风险额度 | X% (上限 3%) |
```

## 目标仓位结构

| 类别 | 建议比例 | 说明 |
|------|----------|------|
| 正股趋势仓 | 50%–65% | 主力仓位 |
| 定义风险期权仓 | 10%–20% | Bull Call Spread 等 |
| USFR / 现金 | 20%–30% | 交易弹药 |

强势市场中可提高风险仓至 80%–90%，但不为满仓买入弱势标的。

## 半导体相关性管理

NVDA、SMH、MU、AVGO、TSM 高度相关，属于同一笔"AI 算力"交易。

- NVDA 做主仓
- SMH 和 MU 通常二选一作为新增重点仓
- 不应把所有半导体标的一起重仓
- 合并计算半导体主题的风险暴露

## 入场方式

只做两类买点：

### 突破买入
- 突破近期平台或 20 日高点
- 成交量明显放大
- 板块同步走强
- 大盘无逆风

### 回踩买入
- 前期已完成有效突破
- 回踩关键均线或突破位
- 支撑未被破坏
- 再次出现上涨确认

## 仓位分配

```text
首仓：账户的 8%–12%
确认盈利后：再增加 5%–10%
趋势继续强化：最后一笔
```

以上仓位比例为参考。每次必须先按 `trade-system.md` 的风险公式计算股数。仓位参考与 0.5%–1% 风险上限冲突时，以风险上限为准。

## 期权决策

### 首选：Bull Call Spread

| 参数 | 设定 |
|------|------|
| 场景 | 日线突破确认后的数周趋势 |
| 到期 | 45–90 天 |
| 买入腿 Delta | 0.55–0.70 |
| 最大损失 | 净权利金，≤ 账户 0.5%–1% |
| 退出 | 盈利 50% 减仓 / 亏损 35%–45% 退出 / 剩余 21 天内平仓 |

### 次选：Long Call

| 参数 | 设定 |
|------|------|
| 场景 | 已确认的最强趋势 |
| 到期 | 至少 60–90 天 |
| Delta | 0.60–0.75 |
| 最大损失 | 全部权利金，≤ 账户 0.5%–1% |

### 不优先：Covered Call

覆盖 Call 会封住强趋势的上涨空间，不适合作为激进趋势账户的主策略。

### 期权通用规则

- 不做裸卖、不做 0DTE、不买深度虚值彩票 Call
- 期权与同方向正股合并计算主题风险
- 不用不同工具伪装成分散

## 新仓检查清单

评估新标的时：

- [ ] 标的是否在候选池或可比范围
- [ ] 现有组合中同主题仓位多少，加起来是否超标
- [ ] 入场是否属于突破买入或回踩买入
- [ ] 能否明确写出结构止损
- [ ] 按风险公式算出的股数是否合理
- [ ] 买入后组合总风险是否在 3% 以内

## 状态记录

每次更新决策文件时区分：
- **已成交**：实际持仓
- **有效挂单**：当前 ORDER 在券商系统中
- **候选计划**：已评估但等待触发
- **已取消**：之前挂单或计划已撤销
