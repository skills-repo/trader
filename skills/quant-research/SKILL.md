# quant-research — 量化研究与回测决策框架

> Agent skill：把"这个系统/因子靠不靠谱"的模糊问题，转成可回测、可证伪、带过拟合检查的研究流程。
> **本技能只做研究与仓位纪律校验，不执行任何自动下单、不杠杆、不做日内高频交易。**

## 触发场景

- 用户问"我的趋势系统过去表现如何""这个均线参数稳不稳""换个周期还灵吗"
- 用户想验证某个因子/信号是否有统计边缘，或担心策略过拟合
- 用户要求做 walk-forward、样本内/外拆分、参数稳定性检验
- 用户要求把回测结果转成仓位风险参考（而非直接放大仓位）
- 用户问 vectorbt / pandas 怎么搭一个可复现的回测

## 角色

你是量化研究纪律助手。你的职责是把主观的"感觉有效"变成可证伪的"数据结论"，并且**永远把回测结果往保守方向解读**——回测赢不代表实盘赢，过拟合的曲线最漂亮。

## 核心纪律（与趋势交易同源）

| 维度 | 设定 |
|------|------|
| 用途 | 只做研究/校验，不做自动执行 |
| 禁止 | 杠杆、日内高频、把回测胜率当保证、过拟合后加大仓位 |
| 数据 | 用调整后收盘价（含分红拆股），避免前复权数据错位 |
| 成本 | 每笔必算手续费 + 滑点，否则收益是假的 |
| 解读 | 样本外表现 > 样本内；参数高原 > 单一尖峰 |

> 回测是"证伪工具"而非"证明工具"：能找到它失效的条件，比找到它赚钱的参数更有价值。

## 研究决策树（问题 → 数据 → 方法 → 解读）

```
开始一项量化研究
│
├─ 步骤 0：明确可证伪假设
│    ├─ "X 突破 20MA 且放量后 20 日上涨概率更高"  → 可测
│    └─ "市场要涨了"                              → 不可测，退回趋势系统判断
│
├─ 步骤 1：数据准备
│    ├─ 时间跨度覆盖牛/熊/震荡（≥ 1 个完整周期）
│    ├─ 调整后收盘价，对齐分红拆股
│    └─ 留出样本外区间（不碰，最后才用）
│
├─ 步骤 2：回测设计
│    ├─ 固定成本（手续费+滑点），禁止零成本
│    ├─ 信号在收盘生成、次日开盘成交（避免未来函数）
│    └─ 参数网格扫描 → 看"参数高原"而非单点最优
│
├─ 步骤 3：稳健性检验
│    ├─ 样本外表现是否仍为正
│    ├─ 不同市场阶段（牛/熊/震荡）是否都不过度退化
│    └─ 去掉最极端 1 年是否结论不变
│
└─ 步骤 4：解读与落地
     ├─ 稳健 → 作为趋势系统的"置信增强"，不改变仓位公式
     └─ 不稳健 → 标注"仅样本内有效"，不进入决策
```

## 回测工作流程（含命令思路）

详见 `references/quant-research-playbook.md`。核心三件事：

1. **可复现**：固定随机种子、固定数据区间、脚本化全过程，结果可重跑。
2. **防未来函数**：任何指标只用"当时可得"的数据；信号 T 日收盘、成交 T+1 开盘。
3. **成本真实**：tick 级做不到就用固定基点（如每笔 0.1% 手续费 + 0.05% 滑点）。

## 过拟合红线（Pitfalls）

1. **参数追寻**：在网格里挑夏普最高的单点 → 几乎必过拟合；要看参数高原。
2. **样本内自慰**：只在训练集好看，样本外崩 → 必须用外样本。
3. **未来函数**：用了当时看不到的数据（盘后公告、未实现指标）→ 结果作废。
4. **零成本幻觉**：不算手续费滑点，收益虚高 30%+。
5. ** survivorship bias**：只用"现在还活着的"股票/币回测 → 自动过滤掉退市标的，虚高。
6. **杠杆放大**：回测漂亮就加杠杆 → 实盘波动直接清仓，本技能禁用。
7. **把回测当保证**：历史表现不代表未来；回测只改"置信度"，不改"单笔风险 0.5%–1%"。
8. **过短数据**：只覆盖一段牛市就下结论 → 必须含熊市与震荡。

## 与趋势系统如何结合

- 回测是**趋势系统的校验层**，不是替代品：趋势系统负责"何时出手"，回测负责"这套出手逻辑历史上多稳"。
- 回测稳健 → 在 `trade-system` 的三层过滤上加一层"历史置信增强"，但**仓位公式不变**（仍按风险金额算）。
- 回测不稳健 → 不否定趋势系统，只标注该参数/因子"仅样本内有效"，退回人工判断。

## 新研究检查清单

- [ ] 假设是否可证伪（不是"市场要涨"）
- [ ] 数据是否含牛/熊/震荡且用调整后价
- [ ] 是否预留未使用的样本外区间
- [ ] 每笔是否计入手续费 + 滑点
- [ ] 信号是否无未来函数（T 收 / T+1 成交）
- [ ] 是否看了参数高原而非单点最优
- [ ] 样本外是否仍为正、各阶段不过度退化
- [ ] 结论是否只改"置信度"、未放大仓位或杠杆

## 状态记录

每次研究区分：
- **已验证**：样本内外稳健，可作置信增强
- **仅样本内**：外样本退化，不进入决策
- **已证伪**：假设不成立，记录失效条件
- **待复核**：数据/成本假设需修正后重跑
