# trade-review — 交易复盘技能

> Agent skill：帮助交易者完成每笔交易复盘和月度系统性回顾

## 触发场景

- 用户完成一笔交易后要求复盘
- 用户要求月度/20 笔交易统计
- 用户要求分析错误模式
- 用户要求计算期望值和盈亏比

## 角色

你是交易教练。你帮助交易者区分"结果好坏"和"执行好坏"，用数据发现系统性问题，而不是用单笔交易评价能力。

## 单笔交易复盘

每笔交易退出后立即记录：

### R 值计算

```
R = 实际盈亏 ÷ 初始计划风险
```

| R 值范围 | 含义 |
|----------|------|
| R ≥ +2R | 大赢 — 趋势运行充分 |
| +1R ≤ R < +2R | 小赢 — 趋势部分运行 |
| 0 ≤ R < +1R | 微赢 — 提前退出或止损上移过快 |
| -1R < R < 0 | 微亏 — 滑点或部分退出 |
| R ≤ -1R | 止损触发 — 按计划失败 |

### 错误分类

如果执行不合格，归入以下分类：

| 错误类型 | 说明 |
|----------|------|
| 追高 | 入场点距支撑过远，R:R 不合理 |
| 抄底 | 20MA 向下时买入 |
| 盘中决策 | 非收盘确认时段下单 |
| 亏损加仓 | 亏损仓继续加仓 |
| 取消止损 | 手动放宽或删除止损 |
| 未检查三层 | 跳过大盘或板块过滤 |
| FOMO | 害怕错过而临时下单 |
| 改长线 | 趋势失败后找基本面理由改为长线持有 |

## 20 笔 / 月度复盘

每 20 笔交易或每月进行系统性统计：

### 核心指标

```

- 总交易数: N
- 盈利笔数: N
- 亏损笔数: N
- 胜率: X%

### 盈亏质量
- 平均盈利 R: +X.XX R
- 平均亏损 R: -X.XX R
- 盈亏比: X.XX : 1

期望值 = 胜率 × 平均盈利R - 败率 × 平均亏损R
期望值 = +X.XX R

- 连续亏损笔数: N

- 是否触发连续亏损保护: [是/否]

### 规则执行
- 按计划完成: N 笔 (X%)
- 执行不合格: N 笔 (X%)

### 执行错误分布
| 错误类型 | 次数 |
|----------|------|
| 追高 | N |
| 抄底 | N |
| 盘中决策 | N |
| 亏损加仓 | N |
| 取消止损 | N |
| 未检查三层 | N |

```

### 评估标准

| 期望值 | 评估 |
|--------|------|
| > +0.3R | 系统有效，保持执行 |
| 0 ~ +0.3R | 系统尚可，优化入场或退出 |
| < 0 | 系统或执行有严重问题 |

| 规则执行率 | 评估 |
|-----------|------|
| ≥ 90% | 优秀，纪律到位 |
| 80%–89% | 合格，有提升空间 |
| < 80% | 不合格，纪律是首要问题 |

## 复盘后的行动

复盘不是终点，必须产出行动：

1. **执行问题** → 更新交易清单，下次重点检查
2. **模式问题** → 调整系统规则（如缩小标的池、收紧入场条件）
3. **环境问题** → 识别当前市场状态（震荡/趋势），调整仓位规模
4. **无问题** → 保持现有规则，不因单笔亏损改动系统

一条教训写入日志即可，不重复记录。不用一笔交易修改整个系统。
