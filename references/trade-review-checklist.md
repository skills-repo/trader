# 交易复盘清单 Playbook

> 本手册是 `skills/trade-review` 的可执行补充。核心目标：把"亏了就是错"的直觉，改成"结果好坏"与"执行好坏"分离的数据复盘。每次退出后立即记单笔，每 20 笔或每月做系统性统计。

---

## 1. 单笔复盘总览

```
一笔交易退出
│
├─ 计算 R 值（结果维度）
│
├─ 拆三阶段执行评估（执行维度）
│    ├─ 入场评估
│    ├─ 持仓评估
│    └─ 退出评估
│
├─ 执行不合格？→ 归入错误分类
│
└─ 写入交易日志（一条教训即可，不重复）
```

**区分结果 vs 执行**：盈利但执行乱 = 运气；亏损但按计划止损 = 执行优秀。评价系统看执行率与期望值，不看单笔盈亏。

---

## 2. R 值计算与含义

```
R = 实际盈亏 ÷ 初始计划风险
```

| R 值范围 | 含义 |
|----------|------|
| R ≥ +2R | 大赢 — 趋势运行充分 |
| +1R ≤ R < +2R | 小赢 — 趋势部分运行 |
| 0 ≤ R < +1R | 微赢 — 提前退出或止损上移过快 |
| -1R < R < 0 | 微亏 — 滑点或部分退出 |
| R ≤ -1R | 止损触发 — 按计划失败 |

**可运行计算（Python）**：

```python
def r_value(pnl, planned_risk):
    return pnl / planned_risk

# 示例：盈亏 +$224，计划风险 $119 → +1.88R
print(round(r_value(224, 119), 2))   # 1.88

# 示例：盈亏 -$112，计划风险 $119 → -0.94R
print(round(r_value(-112, 119), 2))  # -0.94
```

## 4. 错误分类矩阵

| 错误类型 | 说明 | 触发信号 |
|----------|------|----------|
| 追高 | 入场点距支撑过远，R:R 不合理 | 突破前已大涨 |
| 抄底 | 20MA 向下时买入 | 逆风接飞刀 |
| 盘中决策 | 非收盘确认时段下单 | 盘中临时单 |
| 亏损加仓 | 亏损仓继续加仓 | 摊薄成本 |
| 取消止损 | 手动放宽或删除止损 | 不止损 |
| 未检查三层 | 跳过大盘或板块过滤 | 只看个股 |
| FOMO | 害怕错过而临时下单 | 情绪单 |
| 改长线 | 趋势失败后找基本面理由改为长线 | 拒绝止损 |

执行不合格时，必须归入上表之一；一条教训写入日志即可，不重复记录。

## 5. 20 笔 / 月度系统性复盘

```
## 月度复盘｜YYYY-MM
### 基础统计
- 总交易数 / 盈利笔数 / 亏损笔数 / 胜率
### 盈亏质量
- 平均盈利 R / 平均亏损 R / 盈亏比 / 最大单笔盈利 / 最大单笔亏损
### 期望值
期望值 = 胜率 × 平均盈利R − 败率 × 平均亏损R
### 最大回撤
- 连续亏损笔数 / 最大回撤金额 / 回撤占账户 / 是否触发连续亏损保护
### 规则执行
- 按计划完成 N 笔 (X%) / 执行不合格 N 笔 (X%)
### 执行错误分布
- 各错误类型出现次数
```

**期望值计算（Python）**：

```python
def expectancy(win_rate, avg_win_r, loss_rate, avg_loss_r):
    return win_rate * avg_win_r - loss_rate * avg_loss_r

# 示例：胜率 45%，平均盈利 +2.1R，败率 55%，平均亏损 -1.0R
print(round(expectancy(0.45, 2.1, 0.55, 1.0), 3))  # 0.395 → 正期望
```

### 5.1 评估标准

| 期望值 | 评估 |
|--------|------|
| > +0.3R | 系统有效，保持执行 |
| 0 ~ +0.3R | 系统尚可，优化入场或退出 |
| < 0 | 系统或执行有严重问题 |

| 规则执行率 | 评估 |
|-----------|------|
| ≥ 90% | 优秀，纪律到位 |
| 80%–89% | 合格，有提升空间 |
| < 80% | 不合格，纪律是首要问题 |

## 6. 复盘后行动（必须产出，不复盘=白做）

1. **执行问题** → 更新交易清单，下次重点检查
2. **模式问题** → 调整系统规则（缩小标的池、收紧入场）
3. **环境问题** → 识别震荡/趋势，调整仓位规模
4. **无问题** → 保持现有规则，不因单笔亏损改系统

一条教训写入日志即可，不重复记录。不用一笔交易修改整个系统。

## 8. 常见陷阱（Pitfalls）

1. **以单笔盈亏论英雄**：盈利就飘、亏损就改系统 → 看执行率与期望值。
2. **省略 R 值**：只记金额不记 R → 无法跨标的比较质量。
3. **平均亏损被稀释**：用"总亏损÷笔数"掩盖几笔巨亏 → 单独看最大单笔亏损。
4. **复盘不产出行动**：只统计不改进 → 必须落到清单或规则。
5. **连续亏损硬扛**：不触发保护继续重仓 → 连续两笔止损即降风险并复盘环境。
6. **混淆结果和执行**：按计划止损也自责 → 执行优秀即是合格。
7. **篡改计划**：退出后把原止损"合理化"成别的位置 → 以记录为准。

### 9.2 汇总指标（按第 5 节公式）

```
总交易数: 20
盈利笔数: 12   亏损笔数: 8   胜率: 60%
平均盈利 R: +1.74 R
平均亏损 R: -0.94 R
盈亏比: 1.85 : 1
最大单笔盈利: +3.00 R
最大单笔亏损: -1.02 R

期望值 = 0.60 × 1.74 − 0.40 × 0.94 = 1.044 − 0.376 = +0.668 R → 正期望（系统有效）
连续亏损笔数: 2（#3,#4）→ 未触发连续亏损硬保护（阈值 2 笔触发降级，需在 #5 前已复盘）
最大回撤金额: 约 $260（连续两笔亏损期间）
回撤占账户: 260 / 23832 = 1.09%

规则执行:
- 按计划完成: 16 笔 (80%)
- 执行不合格: 4 笔 (20%) → #9 追高, #13 FOMO, 及 #6/#17 提前退出记为合格
```

### 9.3 评估与行动

- **期望值 +0.668R（> +0.3R）** → 系统有效，保持执行。
- **规则执行率 80%（80%–89%）** → 合格，有提升空间；重点整改"追高"与"FOMO"两类情绪错误。
- **行动**：在下月交易清单顶部加两条硬性检查——(a) 入场点距结构止损不得超过每股风险的 3 倍（防追高）；(b) 任何非收盘时段的想法只记录不下单（防 FOMO）。

> 注：本示例为演示数据，真实复盘请用你的券商交割单逐项填入，不套用以上 R 值。
