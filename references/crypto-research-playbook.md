# 加密货币研究 Playbook

> 本手册是 `skills/crypto-trading` 的可执行补充。核心目标：把"要不要研究/建仓某个币"转成一张可逐步打勾的链上 + 结构 + 仓位决策表。
> **研究优先于图表；本手册所有命令只读、不签名、不触发任何链上交易。**

---

## 1. 决策总览树（从宏观到个币）

```
开始评估一笔加密资产
│
├─ 步骤 0：资产分类确认
│    ├─ BTC / ETH                          → 标准流程
│    ├─ 市值前 50 + 上架主流所 + 流动性好  → 标准流程 + 第 5 节筛选
│    └─ 小市值 / 新币 / 未上主流所         → 默认"只观察"
│
├─ 步骤 1：稳定币与宏观背景
│    ├─ 稳定币总供给上升 + BTC 在关键均线上方 → 有利，继续
│    ├─ 稳定币供给收缩                      → 逆风，减仓、不开新仓
│    └─ USDT/USDC 脱锚信号                  → 立即降仓，暂停决策
│
├─ 步骤 2：交易所净流量（囤积 vs 抛压）
│    ├─ 持续净流出（提走自托管）            → 看涨结构
│    └─ 持续净流入（充币到交易所）          → 潜在抛压
│
├─ 步骤 3：链上健康度（NUPL / 实现市值 / 活跃地址）
│    ├─ 实现市值平稳升 + 活跃地址增          → 健康
│    └─ NUPL 进入"狂热"高位                  → 警惕顶部，不加仓
│
├─ 步骤 4：价格结构
│    ├─ HH + HL，关键均线向上，收盘在其上    → 趋势明确
│    └─ 任一不满足                          → 不交易
│
└─ 步骤 5：山寨额外筛选 → 见第 5 节
```

执行顺序严格 **宏观 → 净流量 → 链上 → 结构**；任一层不通过立即回答"不交易 / 只观察"并说明原因。

---

## 2. 链上指标决策矩阵

| 指标 | 有利信号 | 中性/观望 | 逆风/风险信号 | 动作 |
|------|----------|-----------|---------------|------|
| 稳定币总供给 | 上升 | 横盘 | 收缩 | 收缩则不开新仓 |
| 交易所 BTC 净流量 | 净流出 | 持平 | 净流入 | 净流入视为抛压 |
| NUPL | 累积/信念 | 乐观 | 狂热/投降 | 狂热不加仓 |
| 实现市值 | 平稳上升 | 横盘 | 下降 | 下降则降级观察 |
| 活跃地址 | 增长 | 持平 | 萎缩 | 萎缩则怀疑需求 |

**判定规则**：宏观（稳定币）与净流量至少一项"有利"才进入链上；链上健康度不恶化才看结构；结构不满足直接放弃。

## 3. 只读命令（不签名、不含密钥）

> 以下命令仅用于研究。涉及数据商（Glassnode / CoinMetrics）的指标用环境变量传入 key，绝不硬编码。

### 3.1 现货价格（Coingecko 免费，无需 key）

```bash
# 单个币种美元价
curl -s "https://api.coingecko.com/api/v3/simple/price?ids=bitcoin,ethereum&vs_currencies=usd"

# 某币最近市场数据（市值 / 24h 量 / 波动）
curl -s "https://api.coingecko.com/api/v3/coins/markets?vs_currency=usd&ids=bitcoin&price_change_percentage=24h"
```

### 3.2 链上净流量与难度（Blockchain.com 公开 API，无需 key）

```bash
# BTC 当前难度（健康度背景参考）
curl -s "https://blockchain.info/q/getdifficulty"

# 最近区块高度
curl -s "https://blockchain.info/q/getblockcount"
```

> 交易所净流量需聚合多地址标签（Glassnode/CryptoQuant），免费端点无法直接给"净流量"；用上述价格/难度判断宏观，链上细节交给数据商或只读区块浏览器页面。

### 3.3 本地风险金额计算（零依赖）

```python
def crypto_position(account, risk_pct, entry, stop):
    max_loss = account * risk_pct
    per_unit = entry - stop
    if per_unit <= 0:
        return None  # 止损必须在入场下方
    units = int(max_loss // per_unit)
    return {"max_loss": round(max_loss, 2),
            "per_unit_risk": round(per_unit, 2),
            "units": units}

# 示例：账户 $10,000，风险 1%，入场 $60,000，止损 $54,000
print(crypto_position(10000, 0.01, 60000, 54000))
# {'max_loss': 100.0, 'per_unit_risk': 6000.0, 'units': 0}  ← 止损太宽，股数为0，需收紧止损
```

> 上例说明：波动率大的资产若止损设太宽，公式会算出 0 股 —— 这时必须**收窄止损或放弃**，而不是加大仓位去凑数量。

## 4. 仓位与风险公式（必跑，不可凭感觉）

```
单笔最大亏损 ($) = 账户净值 × 单笔风险比例(1%–2%)     # 默认 1%
每单位风险 ($)   = 计划入场价 − 初始止损价
可买数量         = 向下取整(单笔最大亏损 ÷ 每单位风险)
组合总风险       = Σ(每笔计划风险 $) ；要求 ≤ 3%–5% 账户净值
```

**命令化校验**（把持仓风险列成列表求和）：

```python
risks = [100, 80, 60]   # 每笔计划风险 $
total = sum(risks)
print(f"组合风险 ${total}，占比 {total/10000*100:.2f}%")
assert total / 10000 <= 0.05, "组合风险超限"
```

BTC / ETH / 大饼高度相关，合并计入"大盘 crypto"主题风险，不用不同币种伪装成分散。

## 5. 山寨币额外筛选清单（仅 alt，BTC/ETH 跳过）

- [ ] 市值是否在前 50–100，且非"一夜币"
- [ ] 是否在至少一家主流所（Binance/Coinbase/OKX 等）上架
- [ ] 24h 成交量是否足够（避免买不进/卖不出）
- [ ] 团队与路线图是否公开透明（匿名 + 无交付 → 不碰）
- [ ] 代币释放表（unlock schedule）是否已知，近期有无大额解锁
- [ ] 合约是否经审计、有无可疑权限（mint/blacklist/高税）
- [ ] 流动性是否集中在少数地址（拉高出货风险）

任一项不透明 → 标记为"只观察"，不建仓。

---

## 6. 常见陷阱（Pitfalls）

1. **杠杆/合约**：高倍杠杆几小时清零，本手册禁用。
2. **稳定币脱锚**：USDT/USDC 脱锚即全市场流动性塌方，先降仓。
3. **跨链桥被黑**：crypto 头号损失源；不桥接、主仓不放桥上。
4. **scam / 拉高出货**：无流动性、匿名团队、释放不透明 → 不碰。
5. **FOMO 临时单**：24/7 随时暴涨，收盘后（UTC 日界）决策，盘中不交易。
6. **亏损加仓 / 取消止损**：禁止，当日停止交易。
7. **把山寨当分散**：BTC/ETH/大饼高度相关，合并算主题风险。
8. **链上签名诱导**："连接钱包签名领空投/收益"多数为授权盗币，绝不签名。
9. **止损设太宽凑股数**：公式算出 0 股时收紧止损或放弃，而非加仓。
10. **把震荡当趋势**：均线走平还重仓 → 观望期减仓少出手。

```
## 价格结构

[建仓/等待/只观察/不交易] — [原因]
```
