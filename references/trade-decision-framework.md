# 交易决策框架 Playbook

> 本手册是 `skills/trade-system` 与 `skills/trade-decisions` 的可执行补充。核心目标：把"要不要交易"的模糊判断，转成一张可逐步打勾的决策矩阵与一组可复算的公式。所有数字以演示账户净值 $23,832 为例，实际请替换为实时账户。

---

## 1. 决策总览树（从宏观到个股）

```
开始评估一笔交易
│
├─ 步骤 0：账户定位确认
│    └─ 是否属于「趋势小账户」？（与长线主账户隔离）→ 否：停止
│
├─ 步骤 1：大盘环境（SPY / QQQ）
│    ├─ 收盘位于 20MA 上方 且 20MA 向上  → 有利，继续
│    ├─ 20MA 走平、价格来回穿越          → 震荡，减仓、少出手
│    └─ 收盘持续低于 20MA 且 20MA 向下    → 逆风，优先减仓、不开新仓
│
├─ 步骤 2：板块强度（板块 ETF）
│    ├─ 板块 ETF 收盘在 20MA 上方 且 同步走强 → 继续
│    ├─ 同板块多标的同步突破                  → 更可靠
│    └─ 板块 ETF 走弱                        → 个股降级为观察，停止
│
├─ 步骤 3：个股结构
│    ├─ HH + HL 形成、20MA 向上、收盘在 20MA 上方 → 趋势明确
│    └─ 任一不满足                                  → 不交易
│
├─ 步骤 4：买点类型
│    ├─ 有效突破（平台/前高/20日高点，量能放大）→ 进入仓位计算
│    └─ 回踩转强（回踩 20MA/前突破位，重新站上）→ 进入仓位计算
│
└─ 步骤 5：仓位与风险公式 → 见第 3 节
```

执行顺序严格 **大盘 → 板块 → 个股**，任何一层不通过立即回答"不交易"并说明原因。

## 2. 三层过滤决策矩阵

| 层级 | 有利信号 | 震荡信号 | 逆风/弱势信号 | 动作 |
|------|----------|----------|---------------|------|
| 大盘 SPY/QQQ | 收盘>20MA 且 20MA↑ | 20MA 走平，价格穿越 | 收盘<20MA 且 20MA↓ | 逆风则不开新仓 |
| 板块 ETF | 收盘>20MA 且同步 | 分化 | 板块 ETF 走弱 | 走弱则个股降级观察 |
| 个股结构 | HH+HL，收盘>20MA | 无明确结构 | 20MA 向下 | 不满足则放弃 |

**判定规则**：三层全部"有利/同步"才可正常建首仓；一层"震荡"则仓位降到参考下限（首仓 8%）并减少出手；任一层"逆风/弱势"则本笔不交易。

## 3. 仓位与风险公式（必跑，不可凭感觉）

### 3.1 公式

```
单笔最大亏损 ($) = 账户净值 × 单笔风险比例(0.5%–1%)     # 默认 0.5%
每股风险 ($)     = 计划入场价 − 初始止损价              # 结构止损
可买股数         = 向下取整(单笔最大亏损 ÷ 每股风险)
```

### 3.2 可运行计算（Python，零依赖）

```python
def position(account, risk_pct, entry, stop, price_round=1):
    max_loss = account * risk_pct
    per_share = entry - stop
    if per_share <= 0:
        return None  # 止损必须在入场下方
    shares = int(max_loss // per_share)
    return {
        "max_loss": round(max_loss, 2),
        "per_share_risk": round(per_share, 2),
        "shares": shares,
    }

# 示例：账户 $23,832，风险 0.5%，入场 $232，止损 $218
print(position(23832, 0.005, 232, 218))
# {'max_loss': 119.16, 'per_share_risk': 14.0, 'shares': 8}
```

### 3.3 组合风险校验（相关标的合并）

```
组合总风险 = Σ(每只持仓的计划风险 $)
组合风险占比 = 组合总风险 ÷ 账户净值
要求：组合风险占比 ≤ 3%
```

示例：NVDA 两笔 ~$219 + SPCX ~$60 + NEE ~$30 + TSLA ~$15 = $324，占 $23,832 的 1.36% → 通过。

**命令化校验**（把持仓风险列成列表求和）：

```python
risks = [100, 119, 60, 30, 15]
total = sum(risks)
print(f"组合风险 ${total}，占比 {total/23832*100:.2f}%")
assert total / 23832 <= 0.03, "组合风险超限"
```

## 4. 期权决策树

```
评估期权策略
│
├─ 日线突破确认后的数周趋势？
│    └─ 是 → Bull Call Spread（首选）
│         ├─ 到期 45–90 天
│         ├─ 买入腿 Delta 0.55–0.70
│         ├─ 最大损失 ≤ 账户 0.5%–1%
│         └─ 退出：盈利 50% 减仓 / 亏损 35%–45% 退出 / 剩余 21 天内平仓
│
├─ 已确认的最强趋势？
│    └─ 是 → Long Call（次选）
│         ├─ 到期 ≥ 60–90 天
│         ├─ Delta 0.60–0.75
│         └─ 最大损失 ≤ 账户 0.5%–1%
│
└─ 强趋势想收租？
     └─ 否 → 不做 Covered Call（封住上涨空间，不适合激进账户）
```

**期权通用红线**：不做裸卖、不做 0DTE、不买深度虚值彩票 Call；期权与同方向正股合并计算主题风险，不用不同工具伪装成分散。

## 5. 入场检查清单

- [ ] 账户属于趋势小账户，与长线账户隔离
- [ ] 大盘三层过滤已检查并出具判断
- [ ] 板块同步走强，无逆风
- [ ] 个股 HH/HL 完整，收盘在 20MA 上方
- [ ] 买点属于突破买入或回踩转强之一
- [ ] 能明确写出结构止损（跌破则假设失效）
- [ ] 已按公式算股数，股数非 0 且不超出组合 3% 上限
- [ ] 同主题（如半导体）合并风险已计入组合总风险
- [ ] 止损触发不影响睡眠（金额在承受内）

## 6. 常见陷阱（Pitfalls）

1. **抄底**：20MA 向下时因"跌得多、估值低"买入 → 逆风不交易。
2. **追高**：突破前已大涨，入场距支撑太远，无法设合理止损 → 等回踩。
3. **FOMO 临时单**：害怕错过而盘中下单 → 收盘后决策，盘中不交易。
4. **亏损加仓**：亏损仓继续加仓摊薄 → 禁止，当日停止交易。
5. **取消止损**：手动放宽或删除止损 → 禁止，当日停止交易。
6. **伪装分散**：用期权+正股拼成"看似分散"的同方向暴露 → 合并计算主题风险。
7. **用仓位比例覆盖风险上限**：当 8%–12% 首仓参考与 0.5%–1% 风险上限冲突时，**以风险上限为准**。
8. **把震荡当趋势**：20MA 走平还重仓 → 震荡期减仓少出手。
